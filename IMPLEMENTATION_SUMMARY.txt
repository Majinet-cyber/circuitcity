📖 HOW TO USE (For Managers)
───────────────────────────────────────────────────────────────────────────────

1. Navigate to Liquor Dashboard
2. Click "Add Product" button (opens wizard)
3. Select category (e.g., "Beer")
4. Use search box to filter OR scroll through cards
5. Click a product card → Name prefilled automatically
6. Continue with pricing, barcode, and other settings
7. Submit → Product created ✅

Alternative: Click "Custom" to enter manual product name

🔧 HOW TO EXTEND (For Developers)
───────────────────────────────────────────────────────────────────────────────

To Add a New Product:
  Edit: inventory/liquor_catalog.py
  Add to LIQUOR_SUGGESTIONS dict under appropriate category

To Add a New Category:
  1. Add to LIQUOR_SUGGESTIONS dict in liquor_catalog.py
  2. Add to CATEGORY_METADATA dict in liquor_catalog.py
  3. Add to categories array in liquor_wizard.html (Step 1)

To Use Catalog in Other Features:
  from inventory.liquor_catalog import get_all_suggestions
  suggestions = get_all_suggestions()
