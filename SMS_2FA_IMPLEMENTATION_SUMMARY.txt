RATE LIMITING (CACHE-BASED)
================================================================================

SEND OTP:
  - Cooldown: 60 seconds between sends (per user)
  - Max: 3 sends per 10 minutes (per user)
  - Keys: twofa:sms:last_send_at:{user_id}, twofa:sms:send_count:{user_id}

VERIFY OTP:
  - Max: 8 attempts per 10 minutes (per user)
  - Key: twofa:sms:verify_count:{user_id}

EXCEEDED:
  - Message: "Too many attempts. Contact your admin."
  - Not permanent lockout - counters reset after 10 minutes
  - Admin can disable 2FA if needed

USER FLOWS
================================================================================

ENABLE 2FA:
  1. Settings → Security → Two-Factor Authentication
  2. Enter phone number (+265991234567)
  3. Click "Send Verification Code"
  4. Receive SMS with 6-digit code
  5. Enter code → "Verify & Enable 2FA"
  6. ✅ 2FA Enabled

LOGIN WITH 2FA:
  1. Login page → Enter username/password
  2. Redirected to "Verify Your Identity" page
  3. SMS sent automatically to registered phone
  4. Enter 6-digit code
  5. Click "Verify & Continue"
  6. ✅ Access granted, redirected to dashboard

DISABLE 2FA:
  1. Settings → Security → Two-Factor Authentication
  2. Click "Disable 2FA"
  3. Receive SMS with code
  4. Enter code → "Verify & Disable 2FA"
  5. ✅ 2FA Disabled

TROUBLESHOOTING
================================================================================

"SMS verification is not available"
  → Set TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN, TWILIO_VERIFY_SERVICE_SID

"Too many attempts. Contact your admin."
  → Wait 10 minutes OR admin disables 2FA via Django admin

User stuck on challenge page
  → Admin disables 2FA for user via /admin/accounts/usertwofa/

Twilio outage
  → Friendly error shown, admin can disable 2FA temporarily
