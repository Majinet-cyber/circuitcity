# Data Corrections - Manager Quick Start Guide

**Last Updated**: February 5, 2026

---

## 🎯 What is Data Corrections?

The Data Corrections system allows you (as a manager) to safely fix errors in your business data with:
- ✅ **Full audit trail** - Every change is logged
- ✅ **Manager-only access** - Only managers can make corrections
- ✅ **Vertical-aware** - Each business type sees its own correctable data
- ✅ **Instant application** - Changes take effect immediately
- ✅ **Complete history** - See who changed what, when, and why

---

## 🔑 Who Can Use This?

**Only Managers** can access and use data corrections. This ensures:
- Accountability for all data changes
- Prevents unauthorized modifications
- Maintains data integrity

---

## 📍 How to Access

1. Log in as a manager
2. Look in the **sidebar menu**
3. Click **"Data Correction"** (below main navigation items)

**Note:** The button appears in ALL verticals (Phones, Gym, Clothing, etc.) but only if you're a manager.

---

## 📊 What Can Be Corrected?

### Phones Vertical:
- **Phone Sales** - Selling price, cost price, IMEI, payment method
- **Phone Stock** - Cost price, IMEI
- **Accessories** - Product names, SKUs, prices, quantities

### Gym Vertical:
- **Members** - Names, phone numbers, emails, membership fees
- **Payments** - Membership amounts, trainer fees, dates, payment methods
- **Trainers** - Names, contact information

### Clothing Vertical:
- **Products** - Names, sizes, colors, prices, stock quantities
- **Sales** - Quantities, unit prices, totals, payment methods
- **Variants** - Size/color-specific pricing and stock

---

## 🚀 How to Use (Step by Step)

### Quick Edit (Single Record)

1. **Click "Data Correction"** in sidebar
2. **Click on an entity** (e.g., "Gym Members")
3. **Find the record** using search or filters
4. **Click "Edit"** on the record
5. **Make your changes** (update any field)
6. **Enter a reason** (REQUIRED - explain why you're fixing this)
   - Example: "Customer called to report wrong phone number"
7. **Click "Apply Correction"**
8. **Done!** Change is applied immediately and logged

### Browse with Error Detection

1. **Go to Data Correction** dashboard
2. **Click on an entity type**
3. **Toggle "Errors Only"** checkbox
4. System shows potentially problematic records:
   - Sales at a loss (selling price < cost)
   - Negative stock quantities
   - Calculation errors
   - Expired memberships
5. **Fix errors one by one**

## ⚠️ Important Rules

### ✅ DO:
- Always provide a clear, specific reason
- Double-check values before applying
- Review correction history to learn from past fixes
- Use search/filters to find exact records

### ❌ DON'T:
- Make corrections without a valid reason
- Use corrections for routine data entry
- Delete records (use archive/void features instead)
- Share your manager credentials

---

## 📝 Examples of Good Reasons

✅ **Good:**
- "Customer dispute - receipt shows 55,000 but system shows 50,000"
- "Data entry error - transposed digits in IMEI"
- "Member called to update phone number to 0999..."
- "Bank reconciliation found 5,000 MWK difference in payment"

❌ **Bad:**
- "Fix" (too vague)
- "Oops" (not informative)
- "Wrong" (doesn't explain what was wrong)
- "" (empty reason - will be rejected)

## 🕐 Correction History

Every record has a **correction history sidebar** showing:
- Previous changes to this record
- Who made each change
- When it was changed
- Why it was changed

Use this to:
- Track patterns of errors
- Train staff on common mistakes
- Audit suspicious changes
- Learn from past corrections

## 🔍 Audit Trail

Access via: **Dashboard → Audit Trail button**

Shows complete log of ALL corrections:
- Timestamps (to the second)
- User who performed action
- What was changed
- IP address (for security)

**Use cases:**
- Monthly audit reviews
- Investigate discrepancies
- Compliance reporting
- Security investigations

## 💡 Tips & Best Practices

### 1. Search First
Before browsing through pages, use the search box:
- Search by IMEI, product name, member name, etc.
- Saves time finding specific records

### 2. Use "Errors Only"
Toggle this to quickly find problematic records:
- Negative stocks
- Sales at a loss
- Calculation errors

### 3. Check History Before Correcting
If a record has been corrected multiple times:
- Review history to understand the pattern
- May indicate a systematic issue
- Consider training or process improvement

### 4. Be Specific in Reasons
Your future self (and auditors) will thank you:
- Include context (customer call, receipt number, etc.)
- Note the source of truth (physical receipt, bank statement)
- Mention who reported the error if relevant

### 5. Review Dashboard Regularly
Check the dashboard weekly/monthly:
- Spot trends in errors
- Identify training needs
- Ensure corrections are justified

## 🆘 Troubleshooting

### "Data Correction" button not visible?
- Verify you're logged in as a **Manager**
- Contact your business owner if you should be a manager

### Cannot edit a field?
- Some fields are not correctable for safety reasons
- Contact support if you need to change a restricted field

### Correction was wrong - need to undo?
- Contact your business owner or senior manager
- They can rollback corrections using advanced features

### System shows error when applying?
- Check field validations (e.g., IMEI must be 15 digits)
- Ensure values are in correct format
- Try again with valid data
