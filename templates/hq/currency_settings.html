How It Works
  • The exchange rate is stored as a singleton (only one rate exists at a time)
  • When users select USD as their display currency, all MWK amounts are converted using this rate
  • Changing this rate instantly affects the entire app for all users viewing USD
  • All monetary values in the database remain stored in MWK (base currency)
