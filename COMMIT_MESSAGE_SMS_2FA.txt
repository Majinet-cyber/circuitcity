feat: implement optional SMS OTP two-factor authentication

- Users can enable/disable SMS 2FA in account settings
- Post-login OTP challenge for users with 2FA enabled
- Phone number verification (E.164 format)
- Rate limiting: 60s cooldown + 3 sends/10min + 8 verifies/10min
- Step-up authentication decorator for sensitive actions
- Admin rescue path to disable 2FA

- Service: Twilio Verify API integration (send_otp, check_otp)
- Views: Enable/disable/challenge flows with rate limiting
- Middleware: TwoFactorAuthMiddleware enforces challenge before app access
- Decorator: @require_recent_2fa for sensitive actions (password change, etc.)
- Templates: Modern challenge page + functional settings UI
