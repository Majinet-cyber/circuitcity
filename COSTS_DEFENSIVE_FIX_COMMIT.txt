## Changes Summary

### Defensive Improvements
```python
# Before:
context = {
    'fixed_costs': breakdown['fixed'],  # Could KeyError
    'variable_costs': breakdown['variable'],  # Could KeyError
}

# After:
breakdown = breakdown or {}  # Prevent None
context = {
    'fixed_costs': breakdown.get('fixed') or [],  # Safe with default
    'variable_costs': breakdown.get('variable') or [],  # Safe with default
    'fixed_total': breakdown.get('fixed_total') or Decimal('0'),
    'variable_total': breakdown.get('variable_total') or Decimal('0'),
}
```
