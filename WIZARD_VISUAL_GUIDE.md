## Design Tokens

### Colors
- **Primary Blue**: `#3b82f6` - Buttons, active states
- **Blue Light**: `#60a5fa` - Gradients
- **Green**: `#10b981` - Success, completed steps
- **Rose**: `#ef4444` - Errors
- **Yellow/Gold**: `#f59e0b` - Level badges
- **Ink**: `#0b1220` - Text
- **Muted**: `#64748b` - Secondary text
- **Line**: `#dbe3f0` - Borders

### Effects
- **Glassmorphism**: `backdrop-filter: blur(20px)` + semi-transparent background
- **Shadow**: `0 20px 50px rgba(15, 23, 42, 0.15)`
- **Border Radius**: `20px` for cards, `14px` for inputs
- **Animation**: `cubic-bezier(0.17, 0.67, 0.25, 1.35)` (pop effect)

### Typography
- **Font Stack**: `-apple-system, BlinkMacSystemFont, "Segoe UI", Inter, Roboto`
- **Title Size**: `clamp(28px, 4vw, 42px)`
- **Weight**: 900 for headings, 800 for labels, 600 for body

## Mobile Responsive

On screens < 640px:
- Buttons stack vertically
- Progress dots shrink to 32px
- Cards take full width with padding
- Font sizes scale down with clamp()

## Accessibility

- ARIA labels on progress steps
- Semantic HTML5 elements
- Focus states with visible outlines
- High contrast ratios
- Keyboard navigation support
- Form validation messages

## Database Schema

### OnboardingProfile
```sql
CREATE TABLE accounts_onboarding_profile (
  id BIGSERIAL PRIMARY KEY,
  user_id INT NOT NULL UNIQUE REFERENCES auth_user(id),
  goal_stop_theft BOOLEAN DEFAULT FALSE,
  goal_see_profit BOOLEAN DEFAULT FALSE,
  goal_track_performance BOOLEAN DEFAULT FALSE,
  goal_move_off_notebooks BOOLEAN DEFAULT FALSE,
  completed_at TIMESTAMP NULL,
  wizard_version VARCHAR(20) DEFAULT 'v1',
  first_business_name VARCHAR(200),
  first_location_name VARCHAR(200),
  chosen_vertical VARCHAR(50),
  created_at TIMESTAMP NOT NULL,
  updated_at TIMESTAMP NOT NULL
);
```

## Entities Created After Completion

1. **User** (Django auth)
   - username = email
   - email
   - password (hashed)
   - first_name / last_name (split from full_name)

2. **Profile** (accounts.Profile)
   - user (FK)
   - is_manager = True

3. **Business** (tenants.Business)
   - name
   - slug (auto-generated)
   - status = "ACTIVE"
   - business_kind
   - created_by (FK to User)

4. **Membership** (tenants.Membership)
   - user (FK)
   - business (FK)
   - role = "MANAGER"
   - status = "ACTIVE"

5. **Location** (inventory.Location)
   - business (FK)
   - name
   - city
   - is_default = True

6. **OnboardingProfile** (accounts.OnboardingProfile)
   - user (FK)
   - goals (4 booleans)
   - completed_at
   - first_business_name
   - first_location_name
   - chosen_vertical

7. **User Groups**
   - User added to "Manager" group

8. **Session**
   - TENANT_SESSION_KEY = business.pk
