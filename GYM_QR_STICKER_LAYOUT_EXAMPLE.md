# Gym QR Sticker Layout Example

This document illustrates the layout of QR stickers generated by the bulk download feature.

---

## Single Sticker Detail

```
┌───────────────────────────────────┐
│     (Light gray border)           │
│                                   │
│       ┌─────────────┐            │
│       │             │            │
│       │  █████████  │            │
│       │  ███  ████  │  ← QR Code │
│       │  ████  ███  │    (5cm²)  │
│       │  █████████  │            │
│       │             │            │
│       └─────────────┘            │
│                                   │
│    John Doe Smith                │  ← Member Name (bold, 9pt)
│    EW-000123                     │  ← Member Code (7pt)
│    Test Gym                      │  ← Gym Name (6pt, gray)
│                                   │
└───────────────────────────────────┘
     ~70mm x 37mm per sticker
```

### Sticker Components (top to bottom):

1. **Border** (light gray, 0.5pt)
   - Visual guide for cutting
   - Non-intrusive

2. **QR Code** (centered, high-res)
   - Size: ~50mm × 50mm
   - Box size: 10 (high resolution for printing)
   - Error correction: Level M
   - Encodes: `https://emajinet.com/gym/qr/<uuid>/`

3. **Member Name** (bold, centered)
   - Font: Helvetica-Bold, 9pt
   - Truncated if too long (adds "...")
   - Black color

4. **Member Code** (centered)
   - Font: Helvetica, 7pt
   - Format: EW-000123 or GYM-000456
   - Black color

5. **Gym Name** (centered, optional)
   - Font: Helvetica, 6pt
   - Gray color (RGB 0.5, 0.5, 0.5)
   - Truncated if too long

## Dimensions

### Page
- **Size**: A4 (210mm × 297mm)
- **Margins**: 8mm (left/right), 10mm (top/bottom)

### Sticker
- **Width**: ~70mm (calculated to fit 3 per row with gaps)
- **Height**: ~37mm (calculated to fit 8 per column with gaps)
- **Gap between stickers**: 2mm
- **Internal padding**: 2mm

### QR Code
- **Size**: Variable (auto-calculated)
- **Max**: 60% of sticker height or sticker width - padding
- **Typical**: ~50mm × 50mm
- **Resolution**: High (box_size=10, border=1)

## Customization Options

### Change Grid Size

Edit `inventory/views_gym_bulk_qr.py`:

```python
# Current: 3×8 = 24 stickers/page
STICKERS_PER_ROW = 3
STICKERS_PER_COL = 8

# For smaller stickers: 4×10 = 40 stickers/page
STICKERS_PER_ROW = 4
STICKERS_PER_COL = 10

# For larger stickers: 2×6 = 12 stickers/page
STICKERS_PER_ROW = 2
STICKERS_PER_COL = 6
```

Sticker dimensions auto-calculate to fill the page.

### Change Margins

```python
MARGIN_LEFT = 8 * mm    # Distance from left edge
MARGIN_TOP = 10 * mm     # Distance from top edge
MARGIN_RIGHT = 8 * mm    # Distance from right edge
MARGIN_BOTTOM = 10 * mm  # Distance from bottom edge
```

### Change Font Sizes

```python
FONT_NAME_SIZE = 9       # Member name
FONT_CODE_SIZE = 7       # Member code
FONT_LOCATION_SIZE = 6   # Gym name
```

## Printing Tips

### Recommended Paper
- **Type**: A4 sticker sheets (Avery compatible)
- **Finish**: Matte or glossy (your choice)
- **Weight**: 80-100 gsm

### Print Settings
- **Quality**: High/Best (for QR clarity)
- **Color**: Grayscale is fine (QR codes are B&W)
- **Scale**: 100% (do NOT "fit to page" - breaks alignment)
- **Margins**: Use PDF margins, ignore printer margins

### Cutting
- Use the light gray borders as guides
- Scissors or paper cutter work fine
- For precision: X-ACTO knife + ruler

### Testing
1. Print ONE page first
2. Test scan QR codes with phone
3. Verify alignment with your sticker sheets
4. Adjust grid size if needed

## Troubleshooting

### QR Codes Not Scanning
- **Issue**: Low print quality
- **Fix**: Increase FONT_CODE_SIZE or QR_SIZE constants

### Stickers Don't Align with Sheet
- **Issue**: Wrong grid size for your sticker sheets
- **Fix**: Measure your stickers, adjust STICKERS_PER_ROW/COL

### Text Truncated Too Much
- **Issue**: Long member names cut off
- **Fix**: Decrease FONT_NAME_SIZE or increase sticker width

### File Too Large
- **Issue**: 500+ members = big PDF
- **Fix**: Download in batches (filter by active/archived)

## Technical Details

### PDF Library
- **ReportLab** (Python PDF generation)
- Canvas-based drawing (precise positioning)
- No templates needed

### QR Library
- **qrcode** with PIL backend
- Error correction Level M (15% redundancy)
- Quiet zone (border) = 1 module

### Coordinate System
- Origin: Bottom-left corner
- Units: Points (1/72 inch)
- Conversion: 1mm = 2.834645669 points

## Example Member Data in Sticker

```
┌───────────────────────────┐
│   ┌─────────────┐         │
│   │ QR CODE FOR │         │
│   │ UUID: a3b7... │        │
│   └─────────────┘         │
│                            │
│  Jane Smith                │  ← Name from GymMember.name
│  EW-000456                 │  ← From GymMember.member_number
│  Fitness Plus Gym          │  ← From GymMember.business.name
└───────────────────────────┘
```

**Data source**: `GymMember` model
- `member.name` → Name
- `member.member_number` or `member.member_code` → Code
- `member.business.name` → Gym name
- `member.qr_uuid` → QR content (via public URL)
