# Cypress E2E Testing Setup

## Installation

If Cypress is not already installed, run:

```bash
npm install --save-dev cypress
```

## Running Tests

### Open Cypress Test Runner (Interactive)
```bash
npm run cypress:open
```

or

```bash
npx cypress open
```

### Run Tests in Headless Mode (CI)
```bash
npm run cypress:run
```

or

```bash
npx cypress run
```

## Configuration

The Cypress configuration is in `cypress.config.js`:
- Base URL: `http://127.0.0.1:8000`
- Test user credentials are in `env` variables
- Videos are disabled by default to save space
- Screenshots are taken on failure

## Test User Credentials

Update `cypress.config.js` with valid test credentials:

```javascript
env: {
  TEST_EMAIL: 'your-test-user@example.com',
  TEST_PASSWORD: 'your-test-password',
}
```

## Package.json Scripts

Add these to your `package.json`:

```json
{
  "scripts": {
    "cypress:open": "cypress open",
    "cypress:run": "cypress run",
    "test:e2e": "cypress run"
  }
}
```

## Running Django Dev Server for Tests

Before running Cypress tests, ensure Django dev server is running:

```bash
python manage.py runserver
```

## Test Structure

Tests are located in `cypress/e2e/`:
- `phones_dashboard_wallet.cy.js` - Tests phones dashboard and wallet integration

## Adding data-cy Attributes

For more reliable tests, add `data-cy` attributes to your templates:

### Login Template
```html
<input type="email" name="email" data-cy="login-email" />
<input type="password" name="password" data-cy="login-password" />
<button type="submit" data-cy="login-submit">Log In</button>
```

### Profit Panel
```html
<div class="profit-panel" data-cy="profit-panel">
  <div data-cy="profit-revenue">MK {{ revenue }}</div>
  <div data-cy="profit-costs">MK {{ costs }}</div>
  <div data-cy="profit-total">MK {{ profit }}</div>
</div>
```

### Payment Mix Panel
```html
<div class="payment-mix" data-cy="payment-mix-panel">
  <div data-cy="payment-mix-cash">MK {{ payment_mix.CASH }}</div>
  <div data-cy="payment-mix-bank">MK {{ payment_mix.BANK }}</div>
  <div data-cy="payment-mix-mobile">MK {{ payment_mix.MOBILE_MONEY }}</div>
</div>
```

### Navigation
```html
<a href="/inventory/verticals/phones/" data-cy="nav-phones-dashboard">
  Phones Dashboard
</a>
```

## Troubleshooting

### Tests fail with "baseUrl is not set"
- Ensure `baseUrl` is set in `cypress.config.js`
- Default is `http://127.0.0.1:8000`

### Tests fail with connection errors
- Ensure Django dev server is running on port 8000
- Check that the test user credentials are correct

### Tests fail with "element not found"
- Add `data-cy` attributes to templates for more reliable selectors
- Use `cy.wait()` if elements are loaded dynamically

### Tests are flaky
- Increase `defaultCommandTimeout` in config
- Use `cy.wait()` judiciously
- Add explicit waits for AJAX requests

## CI/CD Integration

For GitHub Actions or similar CI:

```yaml
- name: Start Django server
  run: |
    python manage.py migrate
    python manage.py runserver &
    sleep 5

- name: Run Cypress tests
  run: npm run cypress:run
```
