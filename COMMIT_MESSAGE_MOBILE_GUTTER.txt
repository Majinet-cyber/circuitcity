Match landing-page near-edge gutters across app on mobile (global)

PROBLEM:
- App dashboards had cards sitting 30-40px from screen edge on mobile
- Double/triple padding from nested containers (.cc-page → .vertical-page → .container)
- Inefficient use of space, less premium feel compared to landing page
- Landing page uses 1rem (16px) direct gutter with single wrapper
- App pages used multiple nested wrappers with cumulative padding

SOLUTION:
- Created global mobile gutter system in mobile-gutter-system.css
- Single source of truth: CSS variable --cc-gutter-mobile: 10px
- Applied to outermost app content wrapper (.cc-main, main#app-main) only
- Neutralized nested container padding on mobile (container, container-fluid, vertical-page)
- Reduced Bootstrap row gutters to 0.75rem (12px) to match landing page
- Excluded modals, offcanvas, toasts, scanners (no changes to overlays)
- Desktop/tablet layouts completely unchanged (only affects max-width: 576px)

- Created: static/css/mobile-gutter-system.css (476 lines)

  * Mobile: 10px, Tablet: 18px, Desktop: 20px

  * Safety exclusions for overlays
  * No horizontal scroll guarantee
  * Grid system optimization for mobile
