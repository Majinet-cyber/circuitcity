   - Root cause: Hardcoded default in tenants/utils_commission.py
   - Fix: Changed Decimal("0.12") to Decimal("0.03")

   - Root cause: Same as issue #1
   - Fix: Added idempotency check in sales/signals.py

4. **Ranking works in wallet (no more "unavailable")**

   - Fix: Use agent_earnings service (same as dashboard)

   - Fix: Compute dynamic payslips from WalletTransaction
